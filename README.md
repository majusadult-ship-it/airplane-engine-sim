# Aircraft Engine Simulator

A small, responsive, browser-based aircraft engine simulation. Adjust throttle, mixture, and airspeed and watch the engine instruments respond in real time.

## Run it

Open `index.html` in a browser, or start a local static server from this directory:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls and instruments

- Start or stop the simulated engine.
- Adjust throttle, mixture, and airspeed.
- Monitor RPM, estimated power and fuel flow, oil pressure, oil temperature, and cylinder head temperature.
- Observe simplified low-pressure and high-temperature warnings.

This is an educational toy simulation and is not intended for real aircraft operation.
